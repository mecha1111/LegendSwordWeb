# 성검을 얻었는데 몸이 약하다 — UPTRAND

빌드나 설치 없이 사용하는 정적 웹사이트입니다.

## 깃허브에 올리기

ZIP을 푼 뒤 안의 파일과 assets 폴더를 함께 저장소 최상위에 올리세요.
index.html이 저장소 최상위에 있어야 합니다. ZIP 파일 자체를 올리는 것이 아닙니다.
GitHub Pages 게시 위치는 main 브랜치의 루트(/)로 지정하세요.

## 파일 구성

- index.html: 화면 구성, 소개 문구, 팀원
- styles.css: 디자인, 반응형 화면, 애니메이션
- app.js: 메뉴 효과, 상호작용, 다운로드 안내
- site-config.js: 데모 다운로드 주소 설정
- assets/: 게임 이미지, 마우스 커서, 폰트
- .nojekyll: 정적 파일 게시용

## 데모 링크 설정

site-config.js의 demoUrl에 구글 드라이브 공유 링크를 넣으세요.
비어 있으면 “죄송합니다. 현재 데모는 추가 예정입니다.” 안내가 표시됩니다.
변경한 파일을 깃허브에 다시 올려야 게시된 사이트에도 반영됩니다.

## 참고

이미지·폰트·게임 에셋의 권리는 각 권리자에게 있습니다.
이 패키지에는 원본 Unity 프로젝트나 계정 인증 정보가 포함되지 않습니다.
